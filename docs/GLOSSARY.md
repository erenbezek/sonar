# GLOSSARY

| İsim | Anlamı |
|---|---|
| sonar | Projenin adı. |
| büyüme sinyali | Şirketin sitesinde, ilanında ya da GitHub'ında Docker, Kubernetes, bulut, CI/CD veya üründe yapay zekâ geçmesi. Puana eklenir. |
| kart | Telegram'da tek bir şirketi anlatan mesaj. İlgileniyorum, Geç ve Sonra butonlarıyla gelir. |
| izleme listesi | "İlgileniyorum" denen şirketler. Günlük değişiklik kontrolü bunlarda yapılır. |
| adaptör | Tek bir kaynağı (ör. Cyberpark listesi) okuyup ortak biçime çeviren kod parçası. |
